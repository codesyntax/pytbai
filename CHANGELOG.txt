1.7.1 (unreleased)
------------------

- Allow pyOpenSSL 24.2.1 and cryptography 43.0.0. pyOpenSSL 25 removes
  ``OpenSSL.crypto.verify``, which signxml 3.2.2 imports at module level, so
  24.2.1 is a hard upper bound until signxml is upgraded to 4.0 or later
  (signxml 4.0 drops the pyOpenSSL dependency).


1.7.0 (unreleased)
------------------

- Allow signxml 3.2.2, cryptography 42.0.7 and pyOpenSSL 24.1.0.
- Read PKCS#12 files with cryptography instead of the removed
  ``OpenSSL.crypto.load_pkcs12`` (pyOpenSSL 24).
- Add Python 3.12 support; require Python 3.11 or newer.


1.4.10 (unreleased)
-------------------

ADDED:
- Invoice chaining support (EncadenamientoFacturaAnterior) for TicketBAI compliance
- New method: Invoice.set_previous_invoice() to establish the previous invoice in the chain
- New method: Invoice.get_previous_invoice() to retrieve previous invoice data
- Automatic integration of previous invoice data in XML generation
- Unit tests for invoice chaining (tests/test_encadenamiento.py)
- Integration test demonstrating multi-invoice chaining (tests/test_integration_chain.py)

CHANGED:
- Updated TBai.sign() to automatically use invoice's previous_invoice if not explicitly provided
- Updated Invoice.get_dict() to include previous_invoice data when available
- Updated README.md with invoice chaining documentation and examples

FIXED:
- SignatureValue is now automatically truncated to 100 characters as required by TicketBAI specification
